ЧТО ДЕЛАЕТ ЭТА ПРОГРАММА?
================================================================================

Strategy Cloud — это АВТОМАТИЗИРОВАННАЯ ТОРГОВАЯ СИСТЕМА (Algorithmic Trading
Platform), которая работает через терминал MetaTrader 5 и выполняет полный
цикл управления торговым портфелем:

  1. АНАЛИЗ РЫНКА — 81 стратегия анализируют 7 валютных пар (EURUSD, GBPUSD,
     USDJPY, USDCHF, USDCAD, AUDUSD, NZDUSD) на таймфрейме H1.

  2. ГЕНЕРАЦИЯ СИГНАЛОВ — каждая стратегия выдаёт сигнал: LONG (покупка),
     SHORT (продажа) или HOLD (ожидание). Сигналы основаны на:
       • Техническом анализе (RSI, MACD, Bollinger Bands, Ichimoku и др.)
       • Статистических моделях (Random Forest, Logistic Regression)
       • Паттернах объёма (OBV, CMF, Volume Spike)
       • Временных паттернах (день недели, азиатская сессия, гэпы)

  3. РАНЖИРОВАНИЕ — все сигналы проходят через систему composite scoring,
     которая оценивает каждую стратегию по метрикам:
       • Прибыльность (profit) — вес 35%
       • Profit Factor — вес 25%
       • Win Rate — вес 15%
       • Sharpe Ratio — вес 15%
       • Recovery Factor — вес 10%

  4. РАСПРЕДЕЛЕНИЕ РИСКА — Risk Manager определяет:
       • Сколько лотов открыть по каждой стратегии
       • Какие SL/TP установить (стоп-лосс, тейк-профит)
       • Не превышает ли портфель дневной лимит потерь
       • Не упал ли equity до стоп-уровня

  5. ИСПОЛНЕНИЕ — отправка ордеров в MT5 с уникальными magic-номерами
     для каждой комбинации стратегии и параметров.

  6. МЕНЕДЖМЕНТ ПОЗИЦИЙ — трейлинг-стоп на основе ATR (Chandelier Exit):
       • SL двигается только в сторону прибыли
       • TP сохраняется без изменений
       • Проверка каждые N секунд

  7. АДАПТИВНОЕ ПЕРЕРАСПРЕДЕЛЕНИЕ (Steering Wheel) — каждые N дней система
     перераспределяет объём между стратегиями на основе их недавней
     производительности (lookback window).

  8. ОТЧЁТНОСТЬ — ежедневные отчёты с метриками по каждой стратегии,
     дашборд на базе Streamlit с визуализацией.

КЛЮЧЕВЫЕ КОНЦЕПЦИИ
================================================================================

1. ДВА ТИПА СТРАТЕГИЙ:
   ┌──────────────────────────────────────────────────────────┐
   │ OLD-STYLE (34 шт.)                                       │
   │ • Каждая имеет уникальный calc_*(), backtest_*()        │
   │ • Ручные импорты в main.py                              │
   │ • Пример: ema_crossover, rsi_reversal, macd_cross       │
   │                                                          │
   │ STANDALONE (81 шт.)                                      │
   │ • Единый контракт: calc(df, period) → df['k']           │
   │ • Автоматическая регистрация через _registry.py         │
   │ • Generic-циклы в strategy_engine                         │
   │ • Пример: triple_ema, adx_di, ultimate, cmo             │
   └──────────────────────────────────────────────────────────┘

2. STATE-BASED vs VALUE-CROSS:
   ┌──────────────────────────────────────────────────────────┐
   │ STATE-BASED (k ∈ {-1, 0, 1})                             │
   │ • k = +1 → LONG сигнал                                   │
   │ • k = -1 → SHORT сигнал                                  │
   │ • k = 0 → нет сигнала                                    │
   │ • check_entry(prev_k, curr_k) → state_entry()            │
   │ • Пример: ema_crossover, adx_di, rsi_reversal            │
   │                                                          │
   │ VALUE-CROSS (k ∈ ℝ)                                       │
   │ • k = MACD value, RSI value, Z-score, и т.д.            │
   │ • check_entry(prev_k, curr_k) → prev_k <= 0 < curr_k     │
   │ • Пример: macd_cross, rsi_divergence, tsi                │
   └──────────────────────────────────────────────────────────┘

3. СИСТЕМА ОЦЕНКИ (Composite Scoring):
   ┌──────────────────────────────────────────────────────────┐
   │ Score = 0.35 * Profit + 0.25 * ProfitFactor +           │
   │         0.15 * WinRate + 0.15 * Sharpe +                │
   │         0.10 * RecoveryFactor                           │
   │                                                          │
   │ Диапазон: 0–100                                          │
   │ Лот = base_lot * (score / 100)                           │
   └──────────────────────────────────────────────────────────┘

4. MAGIC-ПУЛ [770000..869999]:
   ┌──────────────────────────────────────────────────────────┐
   │ • Каждая стратегия получает уникальный magic номер       │
   │ • Magic = hash(symbol, type, param_key)                   │
   │ • Magic сохраняется при перезапуске (деактивация)        │
   │ • TrailManager мониторит позиции по этому пулу           │
   └──────────────────────────────────────────────────────────┘

5. STEERING WHEEL (Адаптивное распределение):
   ┌──────────────────────────────────────────────────────────┐
   │ • Lookback: N дней (по умолчанию 30)                     │
   │ • Расчёт PnL по каждой категории "символ + семейство"    │
   │ • Перераспределение лотов между стратегиями              │
   │ • Tree Weighting — приоритет сильным стратегиям          │
   │ • Ночной пересчёт + real-time коррекция                  │
   └──────────────────────────────────────────────────────────┘

================================================================================
ОСОБЕННОСТИ И ФИШКИ
================================================================================

1. NO DATA LEAKAGE:
   • ML-модели (Random Forest, Logistic Regression) обучаются
     только на исторических данных (walk-forward)
   • Нет bfill (backfill) — только ffill (forward fill)
   • Признаки рассчитываются с лагом

2. ROBUST ENTRY/EXIT:
   • Пробой по high/low, не по close (избегаем задержки)
   • SL/TP проверяются по реальным high/low бара
   • Учёт спреда при входе

3. FAULT TOLERANCE:
   • Checkpoint per symbol — частичное восстановление
   • Night reset — маркер ночного перерасчёта
   • Backtest history — аудит прогонов

4. INSTITUTIONAL DASHBOARD:
   • Тёмная тема (GitHub-style palette)
   • Plotly визуализация
   • Real-time метрики
   • Статистическая значимость
